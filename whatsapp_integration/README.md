# WhatsApp Business Platform para Odoo 18.0

Este módulo integra Odoo con la API oficial de WhatsApp Business (Meta).

## Características iniciales
- Configuración de credenciales y endpoints de WhatsApp Business Platform.
- Modelos para mensajes, plantillas y configuración.
- Estructura para webhooks (recepción de mensajes/eventos).
- Vistas básicas para administración.

## Próximos pasos sugeridos
- Implementar lógica de envío y recepción de mensajes usando la API de Meta.
- Añadir soporte para adjuntos (PDFs de presupuestos, facturas, etc.).
- Automatización de notificaciones y plantillas.
- Registro de comunicaciones en la ficha del cliente.
- Documentar ejemplos de uso y mejores prácticas.
